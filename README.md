## Overview
The *Domestic Aid Surveillance System* is a home automation and security project designed to integrate intelligent monitoring and control into everyday domestic environments. Built using a **Raspberry Pi Model B**, the system combines surveillance, automation, and smart control functionalities in a single, low-cost platform. It enables real-time monitoring, device control, and alert-based responses to ensure a secure and energy-efficient home.

## Objective
The primary objective of this project is to develop a unified home assistance and surveillance framework that can:
- Provide real-time monitoring of home environments using cameras and sensors.
- Detect unauthorized movements and alert the user instantly.
- Enable remote access and control of home appliances and systems.
- Improve domestic security, reduce energy consumption, and enhance daily convenience.

## Key Features
- **Smart Surveillance:** Human and intrusion detection using PIR and camera modules.  
- **Sensor Integration:** Includes temperature and motion sensors for environmental monitoring.  
- **Remote Accessibility:** Allows users to monitor and control systems through a web interface.  
- **Automation:** Supports device switching and data logging for efficient domestic management.  
- **Scalability:** Can be enhanced with other sensors or integrated with cloud IoT platforms.  

## System Architecture
The system consists of:
- **Raspberry Pi Board (Model B):** Central processing and control unit.  
- **Camera Module:** Captures live video streams for surveillance.  
- **PIR Sensors:** Detect human presence or movement.  
- **Temperature Sensor:** Monitors environmental conditions.  
- **Web Server:** Hosts the interface for remote monitoring and control.  
- **Power and Network Interface:** Provides continuous and remote connectivity.  

### Block Diagram
1. Sensor data and camera feeds are collected by Raspberry Pi.  
2. Raspberry Pi processes the data and triggers alerts or control actions.  
3. The web interface displays live feeds and system data to users.  
4. Users can issue commands remotely to control appliances or surveillance settings.

## Techniques Employed
- **IoT Integration:** To connect sensors and devices through web-enabled communication.  
- **Embedded Systems Programming:** For controlling sensor inputs and GPIO interfaces on the Raspberry Pi.  
- **Web Application Development:** Provides an interactive dashboard for users.  
- **Data Handling:** Data collected is analyzed to optimize automation and alert systems.  
- **Upgradability and Interoperability:** System designed to integrate multiple devices and adapt new features.  

## Results and Usefulness
- Enables users to detect intrusions in real-time while providing seamless remote accessibility.  
- Offers a combined **monitoring + control** solution, unlike existing systems designed for one function only.  
- The system successfully demonstrates smart home automation where **security, control, and energy management** operate together.  
- Can be extended into commercial products for home, office, or elderly-care safety.

## Future Scope
- Integration with voice assistants such as Alexa or Google Home.  
- Cloud-based logging and AI-powered threat detection.
